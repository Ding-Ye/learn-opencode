# learn-opencode

> Build a mini [sst/opencode](https://github.com/sst/opencode) from scratch in Go, session by session — each chapter ends with the upstream TypeScript source.

中文 · [English](./README.en.md)

opencode is a 159K-star open-source AI coding agent (a competitor to Claude Code), written in TypeScript / Bun, packaged as an 18-package monorepo with 183K LOC in the core CLI alone. Reading it top-down is a great way to drown. This repo splits it into 14 chapters; each rewrites one mechanism in 200–600 lines of Go, starting from "make one LLM call work" and growing into tool registry / permission / streaming loop / session persistence / agent registry / MCP / LSP / cost tracking…

## Quickstart

```bash
git clone https://github.com/Ding-Ye/learn-opencode
cd learn-opencode/agents/s01-minimum-loop

export ANTHROPIC_API_KEY=sk-ant-...
go run . hello in three words

# Offline tests (httptest stub for Anthropic)
go test ./...
```

Run the Web doc viewer:

```bash
cd web
npm install
npm run dev
# open http://localhost:3000/en
```

## How to read

1. **Clone locally** (the Web doc viewer needs `docs/` in repo root).
2. **Open a chapter** at `docs/en/sNN-<slug>.md` (English) or `docs/zh/sNN-<slug>.md` (中文).
3. **Run the code**: `cd agents/sNN-<slug> && go test ./...`.
4. **Read upstream**: the "Upstream Source Reading" section at the end of every chapter points to the matching `packages/opencode/src/...` file + line range.

## Stack

- **Go 1.22+** — teaching skeleton. Each chapter is an independent module (via `go.work`); no cross-chapter imports.
- **Next.js 15 + Tailwind 4** — Web doc viewer; renders `docs/{zh,en}/*.md`.
- **GitHub Actions** — Go matrix (vet/build/test per chapter) + web typecheck/build + zh-en parity check.
